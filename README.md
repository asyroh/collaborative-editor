# Real-Time Collaborative Document Editor

Laravel-based collaborative document editor similar to Google Docs.

## Features
- Multi-user editing
- Auto save document
- Live typing indicator
- Revision history
- Last editor tracking
- Conflict resolution (revision tracking)
## Tech Stack
- Laravel
- MySQL
- Axios
- Blade

## Run Project

composer install
npm install
php artisan migrate
npm run dev
php artisan serve
